# Установка NABVE1 (обычный пользователь)

Этот файл — для тех, кто просто скачал готовую сборку (`.exe` под Windows
или `.AppImage` под Linux) и хочет запустить NABVE1, не разбираясь в
Python/venv/pip. Если вы разработчик и запускаете проект из исходников —
вам нужен раздел "Запуск" в [README_RU.md](README_RU.md), а не этот файл.

## Windows

1. Скачайте установщик: **[NABVE1.Setup.0.1.0.exe](https://github.com/Irestm/NABVE1/releases/download/v0.1.0/NABVE1.Setup.0.1.0.exe)**
   (~99 МБ). Браузер может спросить "Сохранить файл?" или показать
   предупреждение вида "Этот файл редко скачивают" — это нормально для
   свежевыложенного файла, жмите "Сохранить"/"Оставить".
2. Запустите скачанный `.exe`. **Windows почти наверняка покажет синий
   экран SmartScreen**: "Windows защитила ваш компьютер" /
   "Windows protected your PC", с кнопкой только "Не запускать". Это не
   вирус и не ошибка — SmartScreen так реагирует на любой .exe без платного
   сертификата подписи (у NABVE1 такого сертификата пока нет). Чтобы
   продолжить: нажмите мелкую надпись **"Подробнее" / "More info"** под
   текстом предупреждения — появится кнопка **"Всё равно выполнить" / "Run
   anyway"**, жмите её.
3. Установщик спросит папку установки и предложит поставить галочки
   "Ярлык на рабочем столе" / "Ярлык в меню Пуск" — оставьте включёнными.
   Установка идёт в вашу пользовательскую папку (`%LOCALAPPDATA%`), поэтому
   прав администратора для самой установки не требуется, и никакого UAC-
   запроса на этом шаге не будет.
4. После установки запустите NABVE1 с ярлыка.

## Linux

1. Скачайте `NABVE1-x.y.z.AppImage`.
2. Сделайте файл исполняемым: правой кнопкой → "Свойства" → "Разрешить
   выполнение как программы" — или в терминале, в папке со скачанным
   файлом:

   ```
   chmod +x NABVE1-*.AppImage
   ```
3. Запустите файл двойным кликом. При первом запуске NABVE1 сам создаст
   себе ярлык в меню приложений — при следующих запусках можно будет
   запускать его оттуда, а не искать файл заново.

## Что происходит при первом запуске

При самом первом запуске (на любой ОС) вместо обычного окна появится
маленькое окно "NABVE1 — первый запуск" с прогресс-баром. В это время
NABVE1 тихо, в фоне, устанавливает всё, что ему нужно для работы —
**никакого окна терминала при этом не появляется**, все эти шаги идут в
фоне, а прогресс-бар просто показывает, на каком мы шаге.

**На Linux**: NABVE1 через системный диалог с паролем (`pkexec` — это
стандартный Linux-диалог для действий, требующих прав администратора, а не
что-то подозрительное) ставит системные пакеты: Python, голосовые движки,
шахматный движок, распознавание текста с экрана и так далее. В том же
шаге ваш пользователь добавляется в системную группу `video` — это нужно
для голосового управления яркостью экрана (реальная подсветка, а не
программное затемнение). **Изменение группы применяется только при
следующем входе в систему**: до первого перезахода после установки
команды яркости будут работать в упрощённом режиме (затемнение через
гамму, без изменения подсветки), после — полноценно. Отдельно ничего
делать не нужно, просто один раз выйдите из системы и зайдите снова
(или перезагрузитесь) когда будет удобно.

**На Windows** шаги первого запуска такие:

1. Если на компьютере ещё нет Python 3.12+ — NABVE1 качает официальный
   установщик Python **напрямую с python.org** (не через winget: на
   некоторых машинах предустановленный в Windows winget сам ломается ещё до
   NABVE1, из-за чего установка вставала намертво) и ставит его тихо, без
   вопросов, только для вашего пользователя (без прав администратора).
2. Затем NABVE1 пытается через `winget` поставить необязательные компоненты
   — LibreOffice (конвертация файлов), FFmpeg (звук), Tesseract (распознавание
   текста с экрана), Stockfish (шахматный движок), Ollama (локальная
   ИИ-модель — реально работает только при наличии видеокарты NVIDIA от
   4 ГБ видеопамяти, на остальных машинах просто ничего не делает).
   Здесь **может один раз появиться системный запрос подтверждения (UAC)**
   — это `winget`, а не NABVE1, просит подтверждения на установку
   конкретного компонента. **Если что-то из этого не установится (сломан
   сам winget) — это не останавливает установку**: NABVE1 всё равно
   запустится и будет работать, просто соответствующая функция
   (конвертация файлов / распознавание текста / шахматы / локальная модель)
   будет недоступна, пока winget не почините отдельно.

Это происходит один раз (пока в приложение не добавят новые зависимости —
тогда точно так же один раз повторится). После этого при каждом обычном
запуске NABVE1 просто сразу открывается и работает.

## Если что-то пошло не так

Если установка не завершилась, окно покажет текст ошибки и две кнопки:

- **"Повторить"** — попробовать ещё раз с того же места (сеть могла на
  секунду отвалиться, или пароль был введён неверно — обычно помогает).
- **"Открыть лог"** — откроет полный технический журнал установки
  (`setup.log`), если хотите разобраться сами или прислать его для помощи.

Лог, настройки и голосовые модели лежат в пользовательской папке приложения:

- Windows: `%APPDATA%\NABVE1\`
- Linux: `~/.config/NABVE1/`

Чтобы принудительно заново пройти установку (например, после сбоя
системного пакета), удалите файл `setup_state.json` в этой папке и
запустите NABVE1 снова — на Linux одной командой:

```
rm ~/.config/NABVE1/setup_state.json
```

## Локальная ИИ-модель на Linux (вручную)

На Windows автоустановщик сам пытается поставить Ollama (см. выше) — это
опционально и реально включается только при наличии видеокарты NVIDIA от
4 ГБ видеопамяти, без неё NABVE1 всё равно прекрасно работает через
облачных ИИ-провайдеров. На Linux у Ollama нет apt-пакета — только свой
установочный скрипт, поэтому автоустановщик его не трогает (не хочется
незаметно для вас качать и выполнять сторонний скрипт с правами
администратора во время обычной установки). Если у вас подходящая
видеокарта и вы хотите локальную модель — откройте терминал и выполните:

```
curl -fsSL https://ollama.com/install.sh | sh
```

Скрипт попросит пароль (`sudo`), сам скачает Ollama и настроит автозапуск.
После этого просто перезапустите NABVE1 — модель (~2 ГБ) сама
скачается при первом вопросе, который до неё дойдёт, отдельно ничего
запускать не нужно.

## Чего автоустановщик сознательно не делает

- Не ставит Ollama/локальную модель на Linux — см. раздел выше.
- Не настраивает Gmail-интеграцию — это требует ваших личных
  ключей доступа и однократного входа, см. README.
