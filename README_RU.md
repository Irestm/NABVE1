# NABVE — NEURAL ASSISTANT BROWSER VERSION 1

GitHub: https://github.com/Irestm/NABVE1

Скачать готовую сборку (v0.1.0): [Windows .exe](https://github.com/Irestm/NABVE1/releases/download/v0.1.0/NABVE1.Setup.0.1.0.exe) · [все релизы](https://github.com/Irestm/NABVE1/releases) — инструкция по установке в [INSTALL.md](INSTALL.md).

Локальный голосовой ассистент («Джарвис») для одного пользователя: FastAPI-бэкенд + Electron/React-интерфейс, с гибридным ИИ (локальная модель на GPU + облачные провайдеры как резерв) и набором модулей для управления компьютером.

---

## Как это устроено

### Голосовой цикл
`ключевое слово → распознавание речи → команда → ответ`

1. **Ключевое слово** (по умолчанию «ассистент») будит цикл — слушает всегда в фоне.
2. **Правила** (`core/voice/intent.py`) сначала пытаются разобрать фразу без ИИ — быстро и надёжно для типовых команд (открыть/выключить/перезагрузить/окна/музыка/планировщик/«что ты умеешь»).
3. Если правило не подошло — фраза уходит **ИИ-классификатору**: тот решает, это команда или обычный вопрос, и достаёт параметры.
4. Ответ озвучивается голосом (Silero/Piper), с учётом выбранного при знакомстве **стиля общения** (влияет и на текст, и на темп/тон голоса).

### Локальная модель + облако
Если на компьютере есть NVIDIA GPU (от 4 ГБ VRAM) — устанавливается и используется **локальная модель** (Qwen2.5, через локальный сервер [Ollama](https://ollama.com)) для простых запросов: быстро, приватно, без интернета. Модель выгружается из видеопамяти после 5 минут простоя и подгружается заново по требованию.

Для сложных запросов (нужны свежие данные, поиск в интернете) или если локальной модели нет/она не уверена — подключается цепочка облачных провайдеров через управляемый браузер: **Gemini → ChatGPT → DeepSeek → Grok**, с автопереключением при достижении дневного лимита.

### «Открой X» — распознавание игр и программ
Голос часто искажает названия («дед селс» вместо Dead Cells). Ассистент сам сканирует, что реально установлено (ярлыки/`.desktop`-файлы, библиотеки Steam), составляет короткий список похожих вариантов и отдаёт его ИИ на выбор вместе с оценкой уверенности. Уверен — открывает сразу; не уверен — переспросит: «Вы имели в виду …?».

### Музыка и видео по настроению
«Включи музыку» без уточнения — спросит: «Какое у вас сегодня настроение?», подберёт трек/видео под ответ и откроет поиск на YouTube. Если сразу назвать что-то конкретное («открой видео с котиками») — переспрашивать не будет.

### Планировщик
«Напомни мне позвонить маме в пятницу» — ассистент сам разберёт, что и когда (включая относительные даты вроде «завтра», «через час»), запишет в календарь и напомнит голосом заранее. Отдельная вкладка «Планировщик» в интерфейсе — календарь на месяц, список ближайших дел, ручное добавление/удаление.

### Стоп-слово
Задаётся при первом знакомстве. Сказали — ассистент перестаёт реагировать на что-либо и просто ждёт в фоне. Повторили то же слово — снова активен.

### Личный профиль (задаётся при первом запуске)
Имя для обращения к вам, как называть саму себя, стиль общения (вежливо / приземлённо / агрессивно / спокойно / с матами / дружелюбно / официально / с юмором — влияет и на лексику, и на темп голоса), голос (6 вариантов, включая случайный), стоп-слово.

## Голосовые команды

| Что сказать | Что произойдёт |
|---|---|
| «Открой steam» / «запусти дед селс» | Откроет приложение/игру (с учётом искажений речи) |
| «Включи музыку» / «открой видео с котиками» | Спросит настроение или сразу откроет по теме на YouTube |
| «Напомни мне купить молока завтра утром» | Запишет в планировщик, напомнит голосом заранее |
| «Что ты умеешь?» / «help» | Расскажет о своих возможностях |
| «Выключи компьютер» / «перезагрузи компьютер» | Выключение/перезагрузка (с подтверждением) |
| «Покажи окно» / «скрой окно» | Управление окном интерфейса |
| «‹стоп-слово›» | Пауза/возобновление реакции на голос |
| «стоп» / «хватит» во время ответа | Прерывает текущий ответ (barge-in) |
| Любой обычный вопрос | Отвечает как обычный ИИ |

Плюс: пароли, поиск в интернете, работа с файлами (docx/xlsx/pdf) — через отдельные модули, см. `modules/`.

## Запуск

**Обычный пользователь**, который просто хочет установить и запустить
готовое приложение (без Python/venv/pip вручную): скачайте установщик
(`.exe` для Windows или `.AppImage` для Linux) и смотрите
[INSTALL.md](INSTALL.md) — при первом запуске всё нужное установится само,
в фоне, без терминала. Дальше в этом разделе — инструкция для запуска из
исходников (нужна разработчикам/контрибьюторам).

### Требования
- Python 3.12, Node.js 18+
- Для распознавания/синтеза речи: микрофон, колонки/наушники
- Опционально: NVIDIA GPU (≥4 ГБ VRAM) для локальной модели
- Системные пакеты (Linux): `python3-tk python3-dev wmctrl xdotool brightnessctl playerctl power-profiles-daemon libnotify-bin libreoffice ffmpeg tesseract-ocr tesseract-ocr-rus stockfish`
- `stockfish` нужен только для голосовых шахматных партий (`modules/board_games`, команда «давай сыграем партию в шахматы»); русские шашки работают без системных пакетов — движок py-draughts чистый Python.
- `brightnessctl` нужен для голосового управления яркостью экрана с реальным управлением подсветкой. apt-пакет ставит udev-правило, дающее группе `video` доступ на запись в `/sys/class/backlight`, но пользователя в эту группу надо добавить самому: `sudo usermod -aG video $USER`, затем перелогиниться. Без `brightnessctl` (или без этой группы) включается запасной путь `xrandr --brightness` — только программное затемнение (гамма), яркость подсветки не меняется.
- Опционально, для голосового управления UI (`modules/ui_automation` — «нажми на X»/«напиши Y» в активном приложении):
  - Десктоп-приложения: `sudo apt-get install python3-gi gir1.2-atspi-2.0`, затем включить accessibility bus в DE (GNOME: Settings → Accessibility) и, отдельно для JetBrains-IDE, их собственную настройку **Settings → Appearance & Behavior → Accessibility → Support screen readers** — это отдельный тумблер, не то же самое, что общесистемный. `scripts/atspi_smoke_test.py` покажет, видит ли AT-SPI конкретное приложение вообще, прежде чем на это рассчитывать.
  - Вкладки Chrome/Chromium: запускать браузер с флагом `--remote-debugging-port=9222` (отдельный ярлык/алиас — подключиться к уже запущенному браузеру задним числом нельзя). Порт меняется через `ASSISTANT_CHROME_CDP_PORT`, если 9222 занят.

### Бэкенд
```bash
pip install -r requirements.txt
# CPU-версия torch (для Silero TTS):
pip install --index-url https://download.pytorch.org/whl/cpu torch
# один раз — для облачных ИИ-провайдеров:
playwright install chromium

python -m core.watchdog
```
Сервер поднимется на `http://127.0.0.1:8756` (порт меняется через `ASSISTANT_PORT`). `watchdog` следит за процессом и перезапускает его при падении.

### Фронтенд (desktop-приложение)
```bash
cd frontend
npm install
npm run dev        # разработка (Vite + Electron)
npm run build      # production-сборка
npm run package    # собрать установщик (electron-builder)
```

### Полезные переменные окружения
| Переменная | Назначение |
|---|---|
| `ASSISTANT_WAKE_WORD` | Ключевое слово (по умолчанию «ассистент») |
| `ASSISTANT_HOST` / `ASSISTANT_PORT` / `ASSISTANT_BIND_HOST` | Адрес и порт сервера |
| `ASSISTANT_WHISPER_MODEL` | Размер модели распознавания речи (`base` по умолчанию) |
| `ASSISTANT_SILERO_SPEAKER` | Голос по умолчанию (можно сменить в настройках) |
| `PORCUPINE_ACCESS_KEY` | Офлайн-движок ключевого слова (опционально) |
| `GROQ_API_KEY` | Бесплатный быстрый ИИ-тир перед облачной цепочкой (опционально) |
| `TELEGRAM_NOTIFY_BOT_TOKEN` / `TELEGRAM_NOTIFY_CHAT_ID` | Исходящие уведомления в Telegram (батарея, напоминания, плагины на ревью) — опционально |

Данные (память о пользователе, пароли, база календаря) хранятся локально в `data/` и шифруются.
