# Разрешение Anthropic на интеграцию с Claude

Anthropic ответили автору проекта письмом и разрешили использовать вход через
подписку Claude в NABVE на условиях ниже. Здесь — **пересказ условий автором
проекта в переводе на русский**; оригинал — письмо команды Anthropic автору
(личные данные и переписка в репозиторий не выкладываются).

## Условия

1. **Только некоммерческое использование.** В проекте явно указано, что он не
   предназначен для коммерческого использования — см. [LICENSE](../LICENSE).
2. **Никаких незаконных целей.** Claude (подписка или API-ключ) не может
   использоваться как «мозг» системы, нарушающей законы страны пользователя.
   Действует также [Usage Policy Anthropic](https://www.anthropic.com/legal/aup).
3. **Возможность подключить свой ключ.** В проекте есть реальная ссылка и
   инструкция, чтобы любой пользователь мог подключить собственный API-ключ
   Anthropic — см. раздел «Подключение ИИ» в [README_RU.md](../README_RU.md).
4. **Проект остаётся бесплатным и открытым.** NABVE нельзя продавать; он должен
   оставаться в свободном доступе. Исключение — отдельные микросервисы, не
   касающиеся коммерческого продукта Anthropic с юридической стороны (например,
   планируемый VPN-микросервис): их продавать разрешено.

## Как это соблюдается в коде

- Режим «Подписка» вызывает **установленный самим пользователем** Claude CLI,
  в который пользователь сам вошёл своим аккаунтом. NABVE никогда не читает,
  не хранит и не передаёт токены или данные входа; переменные
  `ANTHROPIC_API_KEY`/`ANTHROPIC_AUTH_TOKEN` в этот процесс не передаются.
- API-ключ пользователь вводит сам; он хранится только в системном хранилище
  секретов его компьютера.
- В интерфейсе интеграция называется «Claude» / «NABVE — Powered by Claude».
