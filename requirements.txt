# --- core/voice (implemented, lazy-imported: safe to defer install) ---
# Upper bounds below (numpy/torch/faster-whisper/webrtcvad-wheels) are a
# safety net, not a tight pin: these are native-extension packages whose
# ABI compatibility with each other isn't guaranteed across a major bump,
# so a bare `>=` floor risks a clean install silently pulling a future,
# untested combination. Capped one major above what's actually
# tested/working today (numpy 2.5, torch 2.13, faster-whisper 1.2) rather
# than at the currently-installed versions, so routine minor/patch updates
# within the same major still install normally.
